# GPE Research Swarm
### پروژه سوارم پژوهشی رساله: «شکل‌گیری پیمان جهانی محیط زیست و تأثیرات آن بر موافقت‌نامه‌های چندجانبه محیط‌زیستی»

این repository زیرساخت یک **سیستم چند‌ایجنتی (agent swarm)** برای پشتیبانی از تدوین رساله دکتری حقوق بین‌الملل محیط زیست است. در فاز کنونی **فقط ساختار پروژه** ایجاد شده و **هیچ مقاله‌ای خوانده نشده** است.

---

## ساختار پوشه‌ها

```
gpe-swarm/
├── README.md                     ← همین فایل (نمای کلی + فهرست کارها)
├── 00_proposal/                  ← پروپوزال رساله (نسخه اصلی .doc + نسخه خوانا .docx)
├── 01_scenario_and_tasks/        ← سناریوی رساله + TASKS.md (وظایف و پرامپت‌های استخراج‌شده)
├── 02_guidelines/                ← آیین‌نامه نگارش رساله ۱۴۰۰ (PDF)
├── 03_sources/                   ← ۱۹۸ سند پژوهشی، دسته‌بندی‌شده (خوانده‌نشده)
│   ├── GP/  (Articles · Books · UN)
│   ├── MEAs/ (articles · books · UN)
│   ├── Stockholm+50/
│   └── gap/ (+ مقاله/read)
├── 04_prompts/                   ← پرامپت هر ایجنت (استخراج‌شده از وظایف)
├── 05_agents/                    ← کد پایه ایجنت‌ها (scaffold)
├── 06_orchestrator/              ← config.yaml + swarm.py (هماهنگ‌کننده)
├── 07_outputs/                   ← خروجی هر مرحله (فعلاً خالی)
├── 08_manifest/                  ← فهرست ماشین‌خوان همه منابع (JSON + Markdown)
└── 09_docs/                      ← مستندات تکمیلی
```

## معماری سوارم (نگاشت وظیفه ← ایجنت)

| ایجنت | وظیفه | خروجی |
|---|---|---|
| **Orchestrator** | هماهنگی و کنترل کیفیت | — |
| **Source Analyst** | وظیفه ۱: مطالعه عمیق تحلیلی–انتقادی منابع | `07_outputs/01_source_analysis` |
| **Database Researcher** | وظیفه ۲: جستجوی نظام‌مند (Westlaw/HeinOnline/Scopus) | `07_outputs/02_database_search` |
| **Question & Hypothesis Evaluator** | وظیفه ۳: ارزیابی/ارتقاء سؤال‌ها و فرضیه‌ها | `07_outputs/03_questions_hypotheses` |
| **Scenario Analyst** | وظیفه ۴: تحلیل و ارتقاء سناریو | `07_outputs/04_scenario_analysis` |
| **Synthesis Writer** | وظیفه ۵: نسخه پیشنهادی سناریو + فهرست مطالب | `07_outputs/05_final_scenario` |

خط لوله (pipeline): `source_analyst → database_researcher → question_hypothesis_evaluator → scenario_analyst → synthesis_writer`

## اجرا (وضعیت اسکلت)
```bash
pip install -r requirements.txt
python3 06_orchestrator/swarm.py     # فقط وضعیت را چاپ می‌کند؛ هیچ مقاله‌ای خوانده نمی‌شود
python3 08_manifest/build_manifest.py # بازسازی فهرست منابع
```
