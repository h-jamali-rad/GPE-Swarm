# Agent 2 — Database Researcher (جستجوگر پایگاه‌داده) — وظیفه ۲
هدف: جستجوی نظام‌مند در Westlaw، HeinOnline، Scopus و شناسایی منابع مرتبط جدید.
خروجی (در `07_outputs/02_database_search/`):
- راهبرد جستجو (کلیدواژه‌ها، رشته‌های بولی، بازه زمانی).
- فهرست منابع جدید با فراداده کامل و ارزیابی ارتباط/کیفیت.
- شکاف‌های پوششی منابع موجود که باید پر شوند.
نکته: دسترسی به این پایگاه‌ها نیاز به اعتبارنامه دارد؛ در نبود دسترسی، از منابع آزاد/DOI و پیشنهاد رشته جستجو استفاده شود.
