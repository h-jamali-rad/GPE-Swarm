# طرح‌واره «کارت مغزی» هر منبع (Digest Schema)

هر منبع به یک رکورد ساختارمند تبدیل می‌شود (خروجی ایجنت `source_analyst`). فیلدها:

| کلید | نوع | توضیح |
|------|-----|-------|
| `id` | string | شناسه منبع (Sxxx) |
| `title` | string | عنوان تمیزشده |
| `authors` | string | نویسنده/نهاد |
| `year` | string | سال |
| `doc_type` | string | article / book / un_document / thesis |
| `language` | string | en / fa |
| `summary_fa` | string | چکیده مفهومی ۳–۵ جمله‌ای |
| `why_included_fa` | string | چرا این منبع در پژوهش ما (GPE→MEA) هست |
| `key_claims` | list | `{claim_fa, pages:[..]}` — ۴ تا ۸ ادعا/یافته کلیدی با صفحه |
| `citable_excerpts` | list | `{quote (عین متن), page, note_fa}` — گزیده‌های قابل‌استناد با صفحه |
| `dissertation_mapping` | list | `{chapter, how_fa}` — به کدام فصل/بخش رساله خوراک می‌دهد |
| `question_hypothesis_links` | list[str] | کدام پرسش/فرضیه را پشتیبانی می‌کند |
| `research_gaps_fa` | list[str] | چه شکاف پژوهشی‌ای آشکار می‌کند |
| `novelty_fa` | list[str] | چگونه نوآوری کار ما را تقویت می‌کند |
| `relationships` | list | `{type: supports/contradicts/extends/complements, topic_fa}` |
| `themes` | list[str] | برچسب‌های موضوعی (برای گراف و ماتریس) |
| `importance` | string | core / supporting / peripheral |
| `importance_reason_fa` | string | دلیل درجه اهمیت |
| `confidence` | string | high / medium / low (اعتماد استخراج) |
| `_tier` | int | لایه پردازش (۱ تک‌مرحله‌ای، ۲ چانک، ۳ کتاب هدف‌مند) |

## استراتژی سه‌لایه پردازش
- **لایه ۱** (≤ ۵۵هزار کاراکتر): تک‌مرحله‌ای، کل متن با نشانگر صفحه.
- **لایه ۲** (۵۵–۲۲۰هزار): map-reduce؛ چانک روی مرز صفحات، یادداشت جزئی هر چانک، سپس تجمیع.
- **لایه ۳** (> ۲۲۰هزار، کتاب‌ها): امتیازدهی صفحات بر پایه کلیدواژه‌های پژوهش، انتخاب مرتبط‌ترین صفحات + مقدمه/نتیجه، سپس map-reduce. صریحاً به‌عنوان «digest هدف‌مندِ اثر مرجع» علامت‌گذاری می‌شود.

## موضوع/پرسش/فرضیه رساله (زمینه نگاشت)
- **عنوان:** شکل‌گیری پیمان جهانی محیط زیست و تأثیرات آن بر موافقت‌نامه‌های چندجانبه محیط‌زیستی
- **پرسش اصلی:** تأثیر شکل‌گیری پیمان بر MEAها
- **فرضیه:** خلأهای هنجاری + فقدان سند الزام‌آور ← پیمان الزام‌آور موجب نظم/توسعه هنجاری و تبدیل حقوق نرم به سخت
- **فصول:** ۱ چارچوب، ۲ تحول IEL و شکل‌گیری پیمان، ۳ خلأها (A/73/419) و ابتکار پیمان، ۴ تأثیر بر MEA و آینده‌پژوهی (A/CN.4/L.682)، ۵ نتیجه‌گیری
